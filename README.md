Castleberry Swarm
​Welcome to Castleberry Swarm, an open-source multi-agent framework and local network routing tool designed for decentralized, local-first intelligence processing.
​🚀 Core Architecture & Features
​7-Node Hexagonal UDP Mesh: Broadcasts data across local UDP networks (defaulting to port 5280) for robust inter-node communication and decentralized coordination.
​Castleberry Markup Language (CML): A specialized markup system designed for structured multi-agent communication and state synchronization.
​Local Ollama Integration: Executes lightweight local model instances (such as qwen2.5:1.5b) directly in a Termux environment for secure, offline harmonic auditing and inference.
​Tensor Synthesis & Harmonic Baseline: Integrates 2048-point unit-norm tensor synthesis driven by the Golden Ratio (\Phi = 1.618033988749895) and a 528.0\,\text{Hz} baseline frequency.
​SQLite Ledger Archiving: Automatically logs state and network transactions locally into castleberry_ledger.db via castleberry_master_runner.py.
​🛠️ Quick Start & Usage
1. Clone the Repository:
git clone https://github.com/lovelaceyrae11/castleberry_swarm.git
cd castleberry_swarm
2. Run the Master Orchestrator:
python castleberry_master_runner.py
